# Screenshots

Captured from SPECTRE **v1.1.0** running at `http://127.0.0.1:9000/`.

| File | Description |
|------|-------------|
| `console.png` | Web console — 2D pan pad, ±50° tilt rail, goto / halt |
| `console-presets.png` | Console scrolled to the 3×3 sector preset matrix |
| `widget.png` | Floating widget with offline banner, pin, quick-call presets |

Re-capture after UI changes (server must be running):

1. `npm --prefix web run build && npm run server:start`
2. Open console / widget in a browser at 1440×900 (console) or ~420×820 (widget)
3. Save PNGs into this folder with the names above
